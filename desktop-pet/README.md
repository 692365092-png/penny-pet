# Penny 独立桌宠

这是 Penny 的 Windows 桌宠运行端。透明桌宠窗口、拖拽、便利贴、待办、提醒、键盘显示、缩放和开机启动功能都保留；角色动画支持 GIF/逐帧 PNG 美术包。

按键显示对新用户默认关闭，关闭状态不会启动全局键盘监听；可在右键菜单中主动开启。

当前 Windows 发布版本：`1.0`。

桌宠和托盘图标的右键菜单中提供“联系作者”。窗口中的小红书号 `638176366` 可以选中并复制，标识图片不可选中或编辑；单击号码会使用 Windows 默认浏览器打开作者的小红书主页。

## 构建和运行

1. 把美术放在仓库的 `art` 目录，并填写其中的 `pet-art.json`。
2. 在 PowerShell 中运行 `./build.ps1 -OutputFile <输出路径>`。
3. 构建完成后会得到一个内嵌全部运行资源的单文件 EXE。

GitHub 开源发布版使用 `build.ps1` 生成可复现的未混淆二进制，以便审查、自动测试和代码签名。`build-protected.ps1` 仅保留给本地研究用途，不是 GitHub 签名发布流程的一部分。

任何 .NET 混淆都只能显著提高分析成本，无法从理论上保证绝对不可逆。成品中保留了一组给分析者看的英文彩蛋线索，不参与正常功能，也不会重复填充大型无效数据。

构建时会读取 `pet-art.json` 实际引用到的 GIF/逐帧 PNG，把完整源画布、透明通道、帧数和帧时长无损写入按动画懒加载的发布资源包。发布 EXE 不再内嵌、落盘或运行时解析 GIF；发给朋友时仍只需要发送 `Penny桌宠.exe`，不需要附带 `art` 文件夹。

## 美术接口

接口入口：`..\art\pet-art.json`。完整填写说明：`..\art\美术接口说明.md`。

最简单的状态写法：

```json
"idle": {
  "file": "普通待机.gif",
  "speed": 1.0
}
```

- GIF 仍是可直接替换的制作源，构建过程不会降低分辨率、帧数或颜色精度；文件自带的每帧时长会原样进入发布资源包。
- 程序刷新间隔为 15 ms，最终流畅度主要由 GIF 自身的帧时长决定。
- GIF 可以使用任意画布尺寸；运行端会等比放入 192×208 的逻辑画布，并按脚底对齐。
- 尚未绘制的状态可以用 `alias` 临时指向已经完成的状态。
- 也支持按文件名排序的透明 PNG 文件夹，并可为每一帧填写单独时长。

当前状态约定：

| 状态 | 用途 |
|---|---|
| `idle` | 普通待机 |
| `running-right` / `running-left` | 左右移动预留状态 |
| `waving` | 退出动作 |
| `hover` | 鼠标悬停和拖拽 |
| `failed` | 普通待机之二（保留旧内部状态名） |
| `waiting` / `thinking` | 检测到键盘输入时随机播放 |
| `review` | 普通待机之三（保留旧内部状态名） |
| `notification` | 提醒通知 |

## 当前 Penny 美术

- `普通待机.gif`、`普通待机之二.gif`、`普通待机之三.gif`：待机时按权重随机播放；普通待机可以自然连续，两段思考动作不会立即连续重复。
- `鼠标悬停和拖拽 .gif`：鼠标悬停时播放。
- 拖拽人物位置时改用 `普通待机之二.gif`。
- `键盘活动动作之一.gif`、`键盘活动动作之二.gif`：检测到键盘活动时随机播放。
- `提醒通知.gif`：提醒触发时播放。
- `退出动作.gif`：退出程序时完整播放一次。
- `icon.png`：Windows 应用图标源图，构建时使用转换后的 `assets/app.ico`。

目前没有按文件名对应上的“向左移动”和“向右移动”GIF，这两个预留状态暂时复用悬停/拖拽动画。

首次启动直接读取压缩的待机首屏缓存，不再展开 GIF；其余较大的动画从内嵌发布资源包按需解码，并在启动后以低优先级预热常用交互动画。`普通待机之二.gif`、`普通待机之三.gif` 两段思考动作合计占待机循环的 `1/10`（各 `1/20`）；`键盘活动动作之二.gif`（弹琴失败）的键盘触发概率为 `1/6`。点击桌宠随机播放时，这三段动作也使用低权重。

便利贴和待办窗口支持混合磁吸组合：把一张窗口的顶边拖到另一张的底边附近会显示蓝色停靠预览，既可接到末端也可插入中间，宽窄不同的便签只要较窄一方有一半有效重叠也可组合。松手后以最上层窗口的坐标为锚点统一宽度；最上层标题栏始终移动整个组合，不会触发拆分。中间或下层窗口需要先原地长按约半秒、看到橙色分离引导后再拖出；只会抽出被按住的单张，上下邻居立即重新连接，普通拖动不会脱钩。拖动组合内部横向接缝可以重新分配相邻两张便签的高度，原生缩放边界会阻止分隔线越过任一便签的可操作框体。组合统一执行置顶或取消置顶；点击最上层的 × 会把整组收进侧边页签，随后点击组内任意页签都会按照原父子顺序、宽度和高度一次性恢复整个组合；点击中间或下层的 × 只会暂时收起该张，可见的上下邻居会先连接，重新打开该页签时它会插回原来的组内位置。便利贴移除了 Windows 最大化/边缘吸附资格，拖到屏幕边缘不会改变窗口尺寸。

不同 GIF 的原始画布大小不一致，因此每个状态可以用 `renderScale`、`renderScaleY`、`renderOffsetX`、`renderOffsetY` 单独校准。当前数值以 `普通待机.gif` 第一帧的双鞋宽度、中心坐标和脚底基线为统一标准。

对话气泡使用 `RGB(73, 74, 40)` 绿色和白色粗体。普通对话及悬停气泡跟随“按键文字”小/中/大设置；到点提醒仍使用该条提醒中单独设置的字号。

修改 GIF 或配置后重新构建即可，不需要改 C#。开发环境仍可直接读取外置 GIF/PNG；单文件发布版使用 EXE 内嵌的完整分辨率无损资源包。

## 代码结构

- `Program.cs`：桌宠状态机、交互和动画调度。
- `PetArt.cs`：外置美术包读取、GIF 时长解析、完整分辨率发布资源包、状态别名与画布适配。
- `LayeredSpriteRenderer.cs`：Windows 透明分层窗口渲染。
- `StickyNotes.cs` / `StickyNoteTabs.cs`：便利贴、清单和侧边页签。
- `ReminderUi.cs` / `ReminderModels.cs` / `PetSettings.cs`：提醒界面、数据模型与设置持久化。
- `SpeechBubbleForm.cs` / `StartupRegistration.cs`：桌宠气泡与开机启动。
- `GlobalKeyboardActivity.cs` / `KeyboardOverlay.cs`：全局键盘活动与按键显示。
- `PennySelfTests.cs`：自动测试、专项探针和测试预览。

更完整的开发入口、数据恢复说明和高风险兼容逻辑见项目根目录的 `DEVELOPER_GUIDE.md`。

用户数据保存在 `%LocalAppData%\PennyPet`。

启动时若旧版 `sticky-notes.dat` 无法解析，程序会先尝试读取自动生成的 `.bak`；仍无法恢复时会把原文件改名保留为 `.unreadable-时间.bak`，再启用新的可写数据文件。因此旧数据不会被覆盖，新建便利贴也不会因为一次读取失败而永久锁死。
