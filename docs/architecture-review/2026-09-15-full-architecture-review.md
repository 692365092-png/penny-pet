缩小跨线程消息，并让异步结果只有一个提交入口。单纯拆 partial、增加协调器名字或
删除异常处理，不能完成这些目标。

**本轮移除或收紧的具体设计**

1. 分散的实际几何接收逻辑。以前多条路径分别做检查、更新兼容字段、更新 runtime、
   再检查一次。现在在 `StickyFactsReceiver` 准备回执，调用方检查完整操作范围后
   同步提交。prepare 与 commit 之间不运行原生效果、不跨 await、不引入另一套租约。
   这还修复了“窗口事实属于 A，附带内容却属于 B”可被批量路径接受的问题。
2. PetForm 对便利贴全部状态的直接所有权。`StickyWorkspace` 管理宿主、运行态、
   接收器和侧边页签；`StickyDockController` 管理手势、恢复、拓扑操作、mailbox 和
   指示器。释放 Workspace 时先结束其生命周期，再撤销 Dock epoch，避免晚到回调
   提交已结束操作。此处是对象所有权变化，不是把同一个 partial 换个文件名。
3. 几何帧重复深复制内容。`StickyNoteUiSnapshot` 的集合改为只读，内容未改变时复用
   现有快照，只有窗口标志改变时共享内容创建轻量副本；向 canonical 应用相同内容时
   也不重建待办/日程条目。仍比较实际内容，因为编辑器可能在保存时间戳改变前修改数据。
4. 默认启用的同步详细追踪。显示与窗口层级详细追踪改为通过
   `PENNY_DISPLAY_TRACE=1` 显式开启；常见热路径在构造诊断字符串前返回。故障诊断
   保留。普通新建、展开、收起、平铺、删除、排序不再为了不使用的回执等待磁盘。
5. 天气单槽请求状态和定时器排序。`WeatherForecastCache` 先登记共享完成任务，再
   调用提供者；A→B→A 复用 A，B 完成也不会清掉 A。HTTP 传输只处理客户端、截止时间
   和错误降级，Core 缓存不引用 Windows 或 HTTP。
6. 旧版本解析中的十一套布尔值及累积 OR 链。入口一次验证版本及最小字段数，之后按
   字段引入的版本读取。没有升级文件格式，也没有放宽未知版本、截断输入的处理。
   将要求局部变量名必须存在的测试断言改为真实文件行为验证。

**应当保留的约束**

“少写防御代码”不能以破坏边界为代价。以下检查有真实的不确定输入来源：文件大小和
旧版本校验、未知新版本禁止覆盖、导入失败保留原文件、HWND 身份/序号/拓扑代次、
完整批次成员验证、IME 关闭屏障、原生放置失败处理，以及敏感输入检测失败时停止展示
键盘内容。它们应集中在边界，不能因为有 `if`、`catch` 或状态字段就一律删除。

同样，紧急导出写另一个文件，应能在主写入器卡住时独立完成。将所有文件操作都塞进
同一个全局队列，会破坏恢复能力。HostedRuntime 记录当前窗口会话，PlacementRuntime
保留位置与临时安置语义；二者生命周期不同，不能仅为减少类数把它们粗暴合成同一状态。

最终应只有以下明确的写入责任：

| 数据或资源 | 所有者 | 更新来源 |
| --- | --- | --- |
| 用户便签内容、可见性、有序成员、持久位置偏好 | Workspace 中的 canonical 模型 | 已接受的编辑或显式用户操作 |
| HWND、实际 bounds/DPI、原生效果 | StickyUiHost / WindowSession | Windows 观察与已接受命令 |
| Pet 线程接受的实际窗口事实 | FactsReceiver / placement runtime | 验证过的当前会话回执 |
| 一次 Dock 操作的范围、阶段、待执行效果和清理 | DockController 所持有的操作 | 用户意图、当前事实和原生结果 |
| 主存档 revision、dirty、写入顺序和结果 | StickyNoteWriter | 在模型线程捕获的分离快照 |
| 历史文件字段 | Codec 边界 DTO（后续目标） | 文件解析与兼容投影 |

持久偏好和实际位置回答不同问题：前者是用户希望恢复到哪里，后者是 Windows 此刻
把窗口放在哪里。架构目标不是让二者永远相等，而是禁止临时安置意外覆盖用户偏好。

当前文件规模为 PetForm.cs 716 行、StickyWorkspace 1707 行、StickyDockController
2213 行、StickyWindowSession 993 行。PetForm 仍有 shell 的其他 partial。
这些数字只用来说明后续职责压力，不能用“PetForm 单文件变短”代替架构完成度。
